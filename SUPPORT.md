# Getting help

- **Using the app**: start with the [README](README.md); Keychain prompts and installation are covered there and in
  [docs/SIGNING.md](docs/SIGNING.md).
- **Something is broken**: [open a bug report](https://github.com/solitonhq/soliton-term/issues/new?template=bug_report.yml)
  with your version, macOS version and the error text. Remove passwords, private keys and private hostnames first.
- **An idea or a question**: use [Discussions](https://github.com/solitonhq/soliton-term/discussions) or a feature request.
- **A security problem**: do **not** open a public issue; follow [SECURITY.md](SECURITY.md).

This is a community project without a support contract or response-time guarantees. Maintainers answer when they can, and
a well-described, reproducible report is the fastest way to a fix.
